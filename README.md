# Prevista Finance

Single-file books console for **Prevista LLC** (Michigan). Invoices, bills, expenses, chart of accounts, P&L, and monthly close.

**Open in a browser:** [zzombo.github.io/prevista-finance](https://zzombo.github.io/prevista-finance/)

Or download `index.html` and double-click it. No install.

This is **DEMO** data, not live company books. Numbers stay in the browser (localStorage).
